# Data Playlist

A playlist app that uses my own keyless data API to load and browse the Viral 50 USA chart.

## My Links

* **API repository:** https://github.com/TammyAlbinDev/my-data-api
* **API worker:** https://tammy-data-api.lestertammy1977.workers.dev
* **Live playlist app:** https://TammyAlbinDev.github.io/data-playlist/

## What the App Does

The app fetches the 50 tracks from my own API and displays the Position, Track Name, and Artist. The chart can be browsed with Next and Back controls, and tracks can be saved to a Top 5 list.

The app also includes a chat page that sends a question to my API with a POST request and displays the answer.
